# Верстак

Веб-приложение для мебельщика: ввожу размеры корпусной мебели и сразу вижу 3D-модель, получаю чертёж, список деталей, раскрой листов и примерную смету.

## Зачем я это сделала

Когда считаешь корпусную мебель вручную, одну и ту же тумбу приходится пересчитывать несколько раз: размеры, детали, кромка, сколько листов брать. Мне хотелось, чтобы всё это пересчитывалось само, как только меняешь размер, и чтобы результат сразу можно было отдать в цех.

## Что умеет

- Быстрый ввод размеров одной строкой: `600x800x400` или `ш900 в2100 г550`.
- Параметры изделия: ширина, высота, глубина, ножки или цоколь, до 6 секций. В каждой секции дверь, две двери, ящики или открытые полки, число полок, петли слева или справа.
- 3D-модель с текстурой дерева. По клику открываются двери и ящики. Есть разнесённый вид, режим рентгена и размерные линии.
- Чертёж с тремя видами, размерами и штампом. Невидимые линии убираются автоматически.
- Спецификация деталей: одинаковые детали объединяются, считается кромка и фурнитура.
- Раскрой листов с учётом пропила и подрезки, текстурные материалы не поворачиваются.
- Смета: листы, кромка, фурнитура, работа и наценка. Цены и свои материалы редактируются в каталоге.
- Проекты сохраняются в браузере, есть шаблоны, отмена и возврат действий, ссылка на проект и резервная копия в JSON.
- Экспорт: PDF (чертёж, спецификация, смета, раскрой), DXF (виды и раскрой), CSV для Excel, PNG.
- Светлая и тёмная тема, адаптация под телефон.

## Технологии

JavaScript (ES-модули), Vite, Three.js для 3D, jsPDF для PDF. Сервера нет: всё работает в браузере, данные лежат в localStorage. Расчёты вынесены в отдельный слой без привязки к браузеру и покрыты тестами на встроенном `node:test`.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в папку dist
npm run preview    # посмотреть собранную версию
npm test           # тесты
```

## Структура

```
src/
  core/      расчёты: детали, спецификация, раскрой, смета, фурнитура
  data/      каталог материалов и фурнитуры по умолчанию
  drawing/   чертежи: общие примитивы, из них SVG, PDF и DXF
  three/     3D: сцена, материалы, сборка модели, анимация
  export/    скачивание файлов, CSV
  ui/        панели, диалоги, шапка
  styles/    стили
tests/       тесты
```



Размеры везде в миллиметрах. Оси: x вправо, y вверх, z к зрителю.
